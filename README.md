
# 🏋️‍♂️ **FITSPHERE – ONLINE FITNESS TRACKING PLATFORM**

**FitSphere** is a modern, role-based digital fitness platform that enables users to log workouts, track progress visually, and participate in fitness challenges. It replaces manual fitness tracking with a **centralized, secure, and efficient system**.

---

## 🚀 **Project Overview**

FitSphere digitizes fitness management by allowing users to monitor workouts and progress while enabling administrators to manage platform data and users efficiently.

---

## 💡 **Key Features**

✔ Secure login with role-based access

✔ Workout logging and history

✔ Real-time progress visualization

✔ Fitness challenges and rewards

✔ Admin monitoring and analytics

---

## 👥 **User Roles**

### 🛡️ **Admin**

* Manage users and content
* Monitor system activity

### 👤 **User**

* Log workouts
* Track progress
* Join challenges

---

## 🏗️ **System Architecture**

* Role-based authentication
* MVC and OOP principles
* Centralized MySQL database
* Scalable and modular design

---

## 🛠️ **Technology Stack**

| Component | Technology                       |

| Backend   | Java Servlets, JSP               |
| Database  | MySQL                            |

## ▶️ **How to Run**

1. Install **Java JDK**, **Tomcat**, and **MySQL**
2. Import database schema
3. Configure database connection
4. Deploy project on Tomcat
5. Open `http://localhost:8080/FitSphere`
